IMPORTANT:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

https://code.visualstudio.com

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

venv\Scripts\activate

python -m pip install --upgrade pip

pip install -r requirements.txt


If everything worked correctly, you're ready to go.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

8. USING HOMEWORK HELPER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Click the window containing the question.

Wait for the AI to respond.

The AI will display the answer in the Homework Helper window.

Type your answer in.

That's it!
